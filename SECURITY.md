# Security Policy

## Reporting Security Vulnerabilities

The maintainers of [primasdevlabs/sentinel](https://github.com/primasdevlabs/sentinel) take the security of this project seriously. If you believe you have discovered a security vulnerability in Sentinel-12 Security Protocol itself, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

To report a security issue, please contact the maintainers through one of the following methods:
- **Private Disclosure**: Open a [Security Advisory](https://github.com/primasdevlabs/sentinel/security/advisories/new) via GitHub's private vulnerability reporting feature.
- **Repository**: Contact maintainers via [primasdevlabs/sentinel](https://github.com/primasdevlabs/sentinel).

Please include the following information in your report:
- A description of the vulnerability.
- Steps to reproduce the issue or a proof-of-concept script.
- The potential impact of the vulnerability.
- Any suggested remediations or patches.

### Response Timeline

Maintainers will make every effort to:
1. Acknowledge receipt of your report within 48 hours.
2. Provide an estimated timeline for evaluation and fix within 5 business days.
3. Notify you once a security fix or release has been prepared.

## Scope & Authorized Usage Notice

Sentinel-12 Security Protocol is an automated security audit and penetration testing suite.

> **CRITICAL LEGAL NOTICE**: This tool must **ONLY** be executed against your own domain, your own web application, or target systems for which you have explicit, written authorization to perform security testing.

- **Own Application / Domain Scope**: Testing third-party domains, APIs, or infrastructure without prior explicit permission is strictly illegal.
- **Authorized Testing Only**: Always verify that the target URL (`base_url`) belongs to an application environment under your direct control or authorized scope.
- **Tool Security**: Vulnerabilities within Sentinel's runner or web dashboard fall under this security reporting policy.
- **Legal Disclaimer**: Project maintainers accept no liability for unauthorized, illegal, or malicious usage of this security suite.
